Map Name: Crater Lake
Map Type: Skirmish
Map Author: gamemastax
Map Date: 06-09-03 9:48 PM EST (GMT-5)


Map Description: A 2-4 player map with a central area containing 4 oil derricks. Very large base areas with 2 major chokepoints for each base. Garrisonable bunkers are at each chokepoint. There are 4 ways to the center area, and AI has been fully installed.


Map Installation Instructions: Firstly, Create a folder in your 'My Documents\Command and Conquer Generals Data\Maps\' directory named 'Crater Lake'. Extract all files into that directory. Map should be viewable under the unofficial maps section.
